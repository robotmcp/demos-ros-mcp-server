🚀 QUICK START (3 Steps - 5 Minutes)
================================================================================

STEP 1: Install Dependencies (1 min)
────────────────────────────────────
sudo apt update
sudo apt install ros-humble-ignition-gazebo* ros-humble-ros-gz-sim \
  ros-humble-ros-gz-bridge ros-humble-robot-state-publisher \
  ros-humble-joint-state-publisher-gui ros-humble-position-controllers

STEP 2: Build Package (2 min)
────────────────────────────────────
mkdir -p ~/go2_ws/src
cd ~/go2_ws/src
# Copy go2_description folder here
cd ~/go2_ws
colcon build --symlink-install
source install/setup.bash

STEP 3: Launch! (30 sec)
────────────────────────────────────
ros2 launch go2_description gazebo.launch.py world:=simple_flat.sdf

✅ You should see Ignition Gazebo with Go2 robot!

📁 KEY FILES EXPLAINED

go2.urdf
───────
Complete robot description with:
  • 12 joints (4 legs × 3 joints each)
  • Inertial properties for realistic physics
  • Collision shapes for contact detection
  • Visual geometry (using basic shapes, not meshes)
  • Gazebo friction properties
  • Sensor mounts (IMU, Radar)

gazebo.launch.py
────────────────
Ignition Gazebo launcher that:
  • Loads the URDF robot model
  • Initializes the world (SDF)
  • Spawns robot at specified position
  • Starts ROS2 bridges
  • Connects controllers
  • Publishes robot state

go2_controllers.yaml
────────────────────
ROS2 control configuration:
  • Joint trajectory controller (all 12 joints)
  • Individual position controllers
  • PID gain parameters
  • Control update rates
  • Interfaces definition

*.sdf World Files
─────────────────
Gazebo world configuration:
  • Physics parameters (timestep, real-time factor)
  • Ground plane definition
  • Obstacles and terrain features
  • Lighting setup
  • Plugin loading

go2_controller_example.py
──────────────────────────
Interactive Python script demonstrating:
  • Home position movement
  • Squat motion
  • Leg waving
  • Trot gait cycle
  • Forward walking simulation

🎮 EXAMPLE USAGE

================================================================================
🛠️ TROUBLESHOOTING QUICK REFERENCE
================================================================================

Issue: "ros2 command not found"
→ Solution: source /opt/ros/humble/setup.bash

Issue: "Package not found"
→ Solution: colcon build && source install/setup.bash

Issue: "World not found"
→ Solution: Use full path to world SDF file

Issue: Robot not visible in Gazebo
→ Solution: Check terminal for spawn messages, verify URDF

Issue: Simulation too slow
→ Solution: Increase max_step_size in world SDF, disable rendering

Issue: Joint commands not working
→ Solution: Check controller is loaded with 'ros2 control list_controllers'

Issue: High CPU usage
→ Solution: Reduce physics updates, simplify world, use headless mode

Full troubleshooting in README.md!
